# Liberation shriftlari

PDF’ni asl joylashuvni saqlab o‘girishda (`src/lib/files/formats/pdf-layout.ts`) asl shrift o‘rniga ishlatiladi:
Liberation Serif — Times New Roman, Liberation Sans — Arial, Liberation Mono — Courier New bilan bir xil o‘lchamli (metric-compatible)
va lotin hamda kirill harflarini o‘z ichiga oladi.

Litsenziya: SIL Open Font License 1.1 (https://github.com/liberationfonts/liberation-fonts).
